# 课程题库 · 做题练习

面向《通信原理》《电磁场电磁波》课程的刷题小工具。

- 通信原理：186 题（作业一~九 86 题 + 测试一/二 100 题），全部单选，含正确答案与解析
- 电磁场电磁波：30 题（单选 20 + 判断 10），学习通测试一，公式图已内嵌，含正确答案与解析

## 功能

- 自由选题：整份勾选，或点"选题"进入列表逐题勾选
- 混题测试：跨题库自由组合，错题也能勾入
- 练习/测试两种模式：练习答完即判对错并显示解析；测试答完统一出成绩
- 顺序或随机出题，可开启选项乱序
- 错题自动进错题本，可只练错题；错题回顾附解析
- 进度保存在本机浏览器，无需注册登录
- 电脑支持键盘 1–6 选答，回车下一题

## 使用方法

**电脑**：双击 `index.html`，用任意浏览器打开。

**手机（安卓）**：把整个文件夹传到手机，用浏览器打开 `index.html`。
