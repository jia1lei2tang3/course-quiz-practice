# 课程题库 · 中转站

一个链接浏览全部课程题库，各科独立入口，按章节分类刷题。

- 通信原理：186 题（作业一~九 + 测试一/二），按 9 个章节分类
- 电磁场电磁波：30 题（学习通测试一），按章节分类，公式图已内嵌
- 数据通信与网络：362 题（作业 + 课后测试 + 课堂练习）

## 目录结构

```
index.html           中转站首页（科目列表）
通信原理/index.html  科目应用
电磁场电磁波/index.html
数据通信与网络/index.html
sw.js / manifest.webmanifest / icon.svg
```

**新增科目**：把做好的单文件应用复制为 `科目名/index.html`，
再在 `index.html` 的 SUBJECTS 数组里加一行即可。

## 功能

- 自由选题：整份勾选，或点"选题"进入列表逐题勾选
- 混题测试：跨题库自由组合，错题也能勾入
- 练习/测试两种模式：练习答完即判对错并显示解析；测试答完统一出成绩
- 顺序或随机出题，可开启选项乱序
- 错题自动进错题本，可只练错题；错题回顾附解析
- 进度保存在本机浏览器，无需注册登录
- 电脑支持键盘 1–6 选答，回车下一题

## 使用方法

**电脑**：双击 `index.html`，用任意浏览器打开。

**手机（安卓）**：把整个文件夹传到手机，用浏览器打开 `index.html`。
